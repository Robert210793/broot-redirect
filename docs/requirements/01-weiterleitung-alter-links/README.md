# Epic 1: Weiterleitung alter Links

## Übersicht

Entscheidet beim Aufruf einer alten URL, ob direkt weitergeleitet, die Info-Seite angezeigt oder ein Fallback (Standard-Domain, Smart Search) verwendet wird.

> Bestandsaufnahme: Die Stories wurden nachträglich aus dem Code abgeleitet (Stand 2026-10-24) und dokumentieren das Ist-Verhalten.
