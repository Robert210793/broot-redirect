# US-01.001: Automatische Weiterleitung bei Regel mit Auto-Redirect

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Benutzer mit einem alten Dokument-Link
**möchte ich** direkt auf die neue URL weitergeleitet werden, wenn die getroffene Regel dies vorsieht
**damit** ich ohne Zwischenschritt beim gesuchten Dokument lande

## Akzeptanzkriterien

- [x] Trifft eine Regel mit aktivem «Auto-Redirect», antwortet das System mit HTTP 302 auf die transformierte Ziel-URL
- [x] Jede automatische Weiterleitung erzeugt einen Tracking-Eintrag
- [ ] Der Tracking-Eintrag enthält alte und neue URL, Feedback «auto-redirect», Strategie «rule», Regel-ID und Match-Qualität
- [x] Schlägt das Schreiben des Tracking-Eintrags fehl, wird trotzdem weitergeleitet
- [x] Ergibt die Transformation eine leere Ziel-URL, wird nicht weitergeleitet, sondern die Info-Seite angezeigt

## Hinweise

- Neue Regeln werden standardmässig ohne Auto-Redirect angelegt; die Info-Seite ist der Normalfall (siehe US-01.002).
- Der Tracking-Eintrag speichert den Referrer unabhängig von der Einstellung «Referrer-Tracking» (siehe US-09.001).
- Belegende Tests: `RedirectMiddlewareTests`.
