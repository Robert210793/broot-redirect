# US-01.002: Info-Seite als Standard statt direkter Weiterleitung

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Betreiber der alten Adresse
**möchte ich**, dass alte Links standardmässig auf eine Info-Seite statt direkt auf das Ziel führen
**damit** Benutzer bemerken, dass ihr Link veraltet ist, und ihre Verknüpfungen aktualisieren

## Akzeptanzkriterien

- [x] Trifft eine Regel ohne aktives «Auto-Redirect», leitet das System nicht weiter, sondern liefert die Info-Seite aus
- [x] Die Info-Seite löst den aufgerufenen Pfad (inklusive Query) über die API auf und erhält Regel, Ziel-URL, Score, Match-Qualität und Ampelstufe
- [x] Fehlt der Pfad bei der Auflösung oder ist er leer, antwortet die API mit 400
- [ ] Eine neu angelegte Regel hat «Auto-Redirect» standardmässig deaktiviert

## Hinweise

- Auf dem Weg zur Info-Seite läuft das Matching zweimal: einmal beim Aufruf der alten URL (Entscheid über Auto-Redirect) und einmal bei der Auflösung durch die Info-Seite. Beides sind reine Cache-Zugriffe.
- Belegende Tests: `RedirectMiddlewareTests`, `RedirectControllerTests`.
