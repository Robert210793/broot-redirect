# US-02.001: Alte und neue URL auf der Info-Seite anzeigen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Benutzer mit einem alten Link
**möchte ich** auf einer Info-Seite sehen, dass mein Link veraltet ist und wie die neue URL lautet
**damit** ich das Dokument öffnen und meine Verknüpfung aktualisieren kann

## Akzeptanzkriterien

- [ ] Während der Auflösung zeigt die Seite «URL wird analysiert...»
- [ ] Die Kopfzeile zeigt den konfigurierten Kopfzeilen-Titel
- [ ] Bei einem Treffer oder Smart-Search-Fallback zeigt die Karte «URL-Vergleich» die neue URL und die alte aufgerufene URL mit den konfigurierten Beschriftungen
- [ ] Die alte URL wird aus dem tatsächlich aufgerufenen Pfad inklusive Query gebildet; ein Base-Href der Anwendung wird dabei entfernt
- [ ] Im Anzeigemodus «inline» steht ein Warnhinweis mit dem konfigurierten Titel und der Nachricht direkt über dem URL-Vergleich
- [ ] Im Anzeigemodus «active» erscheint zuerst ein Dialog mit Titel und Nachricht; die Schaltfläche «Zeige mir die neue URL» oder ein Klick ausserhalb schliesst ihn und gibt den URL-Vergleich frei
- [ ] Ohne Treffer und ohne Smart Search zeigt die Seite «Seite nicht gefunden», die Erklärung für «kein Treffer», die alte URL und — falls eine Standard-Zieldomain gesetzt ist — die Schaltfläche «Zur neuen Startseite» (öffnet in neuem Tab)
- [ ] Können die Einstellungen nicht geladen werden, wird die Auflösung trotzdem ausgeführt und es gelten die eingebauten Standardtexte

## Hinweise

- Alle Texte (Titel, Nachricht, Beschriftungen) sind Laufzeit-Einstellungen (siehe US-10.002).
- Für das Frontend existieren keine automatisierten Tests.
