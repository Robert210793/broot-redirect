# US-02.002: Neue URL kopieren oder in neuem Tab öffnen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Benutzer auf der Info-Seite
**möchte ich** die neue URL mit einem Klick kopieren oder öffnen
**damit** ich meine Verknüpfung ohne Abtippen aktualisieren oder das Dokument sofort aufrufen kann

## Akzeptanzkriterien

- [ ] Die Schaltfläche «URL kopieren» kopiert die neue URL in die Zwischenablage und zeigt für 2,5 Sekunden «Kopiert!»
- [ ] Ein Klick auf das Feld mit der neuen URL kopiert diese ebenfalls
- [ ] Die Schaltfläche «In neuem Tab öffnen» öffnet die neue URL in einem neuen Browser-Tab
- [ ] Die Beschriftungen beider Schaltflächen sind in den Einstellungen anpassbar
- [ ] Beim Smart-Search-Fallback wirken beide Aktionen auf die Such-URL

## Hinweise

- Kopieren oder Öffnen löst — sofern aktiviert — die Feedback-Umfrage aus (siehe US-02.005).
