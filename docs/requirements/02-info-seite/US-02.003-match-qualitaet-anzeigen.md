# US-02.003: Match-Qualität auf der Info-Seite anzeigen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Benutzer auf der Info-Seite
**möchte ich** sehen, wie zuverlässig die neue URL ermittelt wurde
**damit** ich einschätzen kann, ob ich der neuen URL vertrauen oder besser selbst suchen soll

## Akzeptanzkriterien

- [ ] Eine Anzeige im URL-Vergleich zeigt die Match-Qualität in Prozent und farbig nach Ampelstufe (grün, gelb, rot)
- [ ] Die Anzeige erklärt die Qualität mit dem konfigurierten Text: ab 90 % «hoch», ab 60 % «mittel», darunter «tief»
- [ ] Beim Smart-Search-Fallback wird die Erklärung für «kein Treffer» verwendet
- [ ] Die Anzeige ist für Screenreader mit Qualität und Erklärung beschriftet

## Hinweise

- Die Berechnung der Qualität ist in US-03.007 beschrieben.

## Offene Fragen

- [ ] **F1 · Schalter «Link-Qualitätsanzeige» ohne Wirkung:** Die Einstellung `ShowLinkQualityGauge` wird gespeichert und im Admin-Panel angeboten, die Info-Seite zeigt die Anzeige aber immer an.
  - Option A: Info-Seite blendet die Anzeige aus, wenn der Schalter deaktiviert ist — ✅ Einstellung wirkt wie im Admin-Panel beschrieben / ❌ kleine Frontend-Änderung nötig
  - Option B: Schalter entfernen — ✅ kein irreführender Schalter mehr / ❌ Möglichkeit zum Ausblenden entfällt
  - **Empfehlung:** Option A, weil das Admin-Panel und die Dokumentation das Ausblenden bereits versprechen.
