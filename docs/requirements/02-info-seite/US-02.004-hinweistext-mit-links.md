# US-02.004: Hinweistext mit klickbaren Links anzeigen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** auf der Info-Seite einen Hinweistext anzeigen, global oder pro Regel
**damit** Benutzer zusätzliche Informationen zur neuen URL erhalten, etwa wo sie Inhalte selbst suchen können

## Akzeptanzkriterien

- [ ] Im URL-Vergleich steht ein Hinweisbereich mit dem konfigurierten Hinweis-Titel
- [ ] Hat die getroffene Regel einen eigenen Info-Text, wird dieser angezeigt, sonst der globale Hinweistext
- [ ] `http(s)`-URLs im Hinweistext sind klickbar und öffnen in einem neuen Tab; ein Satzzeichen direkt nach der URL gehört nicht zum Link
- [ ] Der Hinweistext wird vor dem Erzeugen der Links vollständig HTML-maskiert, sodass eingegebenes HTML als Text erscheint

## Hinweise

- Die Reihenfolge «zuerst maskieren, dann verlinken» ist sicherheitsrelevant und muss bei Änderungen erhalten bleiben.
