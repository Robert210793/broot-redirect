# US-02.005: Feedback zur Weiterleitung geben

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Benutzer auf der Info-Seite
**möchte ich** rückmelden, ob die neue URL funktioniert hat, und bei Bedarf die richtige URL vorschlagen
**damit** fehlerhafte Regeln erkannt und korrigiert werden können

## Akzeptanzkriterien

- [ ] Die Umfrage erscheint nur, wenn die Einstellung «Feedback-Umfrage» aktiv ist und der Aufruf erfolgreich erfasst wurde
- [ ] Die Umfrage erscheint nach dem ersten Kopieren oder Öffnen der neuen URL, höchstens einmal pro Seitenaufruf
- [ ] Die Frage «Hat die Weiterleitung funktioniert?» bietet «Ja» und «Nein»; «Ja» speichert das Feedback `OK`
- [ ] Nach «Nein» folgt der Schritt «Kennen Sie die korrekte URL?» mit einem Eingabefeld; «Absenden» speichert `NOK` mit der vorgeschlagenen URL, «Überspringen» speichert `NOK` ohne URL
- [ ] Nach dem Speichern erscheint «Danke für Ihr Feedback!» und der Dialog schliesst sich nach 2 Sekunden
- [ ] Ein Klick ausserhalb des Dialogs schliesst ihn ohne Feedback; ein Fehler beim Speichern schliesst ihn ebenfalls

## Hinweise

- Speichern und Validieren des Feedbacks auf der API ist in US-09.001 beschrieben.

## Offene Fragen

- [ ] **F1 · Schalter «Feedback-Kommentar» ohne Wirkung:** Die Einstellung `EnableFeedbackComment` wird gespeichert und im Admin-Panel angeboten («Nur einfaches OK/NOK»), die Info-Seite zeigt nach «Nein» aber immer den Schritt zum Vorschlagen der URL.
  - Option A: Info-Seite speichert bei deaktiviertem Schalter nach «Nein» direkt `NOK` ohne Vorschlagsschritt — ✅ Einstellung wirkt wie beschrieben / ❌ kleine Frontend-Änderung nötig
  - Option B: Schalter entfernen, Vorschlagsschritt bleibt immer aktiv — ✅ kein irreführender Schalter / ❌ Administratoren können den Schritt nicht abschalten
  - **Empfehlung:** Option A, weil das Admin-Panel den Schalter bereits mit dieser Bedeutung anbietet.
- [ ] **F2 · Anrede im Feedback-Dialog:** Der Feedback-Dialog verwendet die Sie-Form («Bitte bewerten Sie…»), die übrigen Standardtexte der Info-Seite die Du-Form («Du verwendest einen alten Link…»).
  - Option A: Feedback-Dialog auf die Du-Form umstellen — ✅ einheitliche Anrede / ❌ Textänderung für bestehende Benutzer
  - Option B: Beide Formen belassen — ✅ keine Änderung / ❌ uneinheitliche Anrede auf derselben Seite
  - **Empfehlung:** Option A, weil die konfigurierbaren Standardtexte bereits die Du-Form verwenden.
