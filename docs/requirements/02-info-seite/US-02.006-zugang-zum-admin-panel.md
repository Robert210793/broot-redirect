# US-02.006: Zugang zum Admin-Panel von der Info-Seite

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** von jeder Info-Seite aus ins Admin-Panel gelangen
**damit** ich eine auffällige Weiterleitung direkt korrigieren kann

## Akzeptanzkriterien

- [ ] Die Fusszeile der Info-Seite enthält ein dezentes Zahnrad-Symbol «Administrator-Bereich»
- [ ] Ein Klick prüft den Anmeldestatus; während der Prüfung ist das Symbol deaktiviert und zeigt einen Ladeindikator
- [ ] Ist der Administrator angemeldet, öffnet sich die Regelverwaltung
- [ ] Ist er nicht angemeldet oder schlägt die Prüfung fehl, erscheint ein Passwort-Dialog; nach erfolgreicher Anmeldung öffnet sich die Regelverwaltung
