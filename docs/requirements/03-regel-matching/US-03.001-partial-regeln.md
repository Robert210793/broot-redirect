# US-03.001: Teilweise Regeln (Präfix-Abgleich) auf Pfadabschnitte anwenden

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** eine Regel für einen Pfadabschnitt anlegen, die alle darunterliegenden alten URLs abdeckt
**damit** ich ganze Bereiche mit einer einzigen Regel umleiten kann, statt jede URL einzeln zu erfassen

## Akzeptanzkriterien

- [x] Die Pfadsegmente des Matchers werden an jeder Position im Pfad der Anfrage gesucht, nicht nur am Anfang
- [x] Ein Segment `*` oder `:name` im Matcher passt auf ein beliebiges Segment der Anfrage
- [x] Ein Segment `präfix*` passt auf jedes Segment, das mit dem Präfix beginnt
- [x] Ein Matcher mit mehr Segmenten als die Anfrage wird übersprungen
- [x] Deckt der Matcher den Pfad vollständig ab, beträgt die Qualität 100; trifft er nur einen Teil (z. B. ein Präfix), beträgt sie 50
- [x] Teilweise Regeln werden erst geprüft, wenn keine Regel vom Typ «Wildcard» greift
- [x] Bei mehreren passenden teilweisen Regeln gewinnt die mit dem höheren Score (siehe US-03.006)

## Hinweise

- Im Admin-Panel heisst der Typ «Teilweise (Präfix-Abgleich)»; er ist der Standardtyp neuer Regeln.
- Score einer Pfad-Regel: getroffene statische Segmente × Gewicht Pfadsegment + getroffene Query-Paare × Gewicht Query-Paar + Wildcard-Segmente × Wildcard-Wert + Bonus bei exaktem Treffer. Die Gewichte sind Startkonfiguration (siehe US-03.008).
- Belegende Tests: `RuleMatchingServiceTests`.
