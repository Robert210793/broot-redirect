# US-03.005: Query-Parameter beim Matching abgleichen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** Regeln auf bestimmte Query-Parameter einschränken
**damit** alte URLs, die sich nur in der Query unterscheiden (z. B. Dokument-IDs), auf unterschiedliche Ziele zeigen können

## Akzeptanzkriterien

- [x] Jedes Key/Value-Paar im Matcher einer Regel muss in der Anfrage vorkommen, sonst greift die Regel nicht
- [x] Die Anfrage darf zusätzliche Parameter enthalten; dies senkt die Qualität auf 75
- [x] Jedes getroffene Paar erhöht den Score um das Gewicht «Query-Paar»
- [x] Mehrfach vorkommende Keys werden zusammengeführt; die Werte werden für den Vergleich sortiert
- [x] Keys werden ohne Beachtung der Gross-/Kleinschreibung verglichen, ausser der Query-Vergleich ist als case-sensitiv konfiguriert

## Hinweise

- Belegende Tests: `RuleMatchingServiceTests`.
