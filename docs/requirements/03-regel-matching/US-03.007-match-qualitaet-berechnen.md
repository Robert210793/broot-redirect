# US-03.007: Match-Qualität und Ampelstufe berechnen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Benutzer mit einem alten Link
**möchte ich**, dass jede Zuordnung eine nachvollziehbare Qualitätsstufe erhält
**damit** ich und die Administratoren erkennen, wie genau die neue URL zur alten passt

## Akzeptanzkriterien

- [x] Exakter Treffer (Pfad und Query vollständig abgedeckt): Qualität 100
- [x] Treffer mit zusätzlichen, der Regel unbekannten Query-Parametern: Qualität 75
- [x] Pfad-Regel, die nicht am Anfang greift, weniger Segmente abdeckt als die Anfrage hat oder ein `präfix*`-Segment nutzt: Qualität 50
- [x] Regex-Treffer: Qualität 100
- [ ] Ampelstufe: ab 90 grün, ab 60 gelb, darunter rot
- [x] Smart-Search-Fallback: Qualität 0, Stufe rot

## Hinweise

- Jede Stufe hat einen eigenen, im Admin-Panel editierbaren Erklärungstext (siehe US-10.002).
- Belegende Tests: `RuleMatchingServiceTests`, `RedirectControllerTests`.
