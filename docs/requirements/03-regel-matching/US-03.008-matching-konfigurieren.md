# US-03.008: Matching über die Startkonfiguration steuern

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Betreiber
**möchte ich** Gross-/Kleinschreibung, abschliessende Schrägstriche und die Score-Gewichte des Matchings konfigurieren
**damit** sich das Matching an die Eigenheiten der alten URLs anpassen lässt

## Akzeptanzkriterien

- [x] Pfade werden standardmässig ohne Beachtung der Gross-/Kleinschreibung verglichen; mit «Pfad case-sensitiv» wird sie beachtet
- [x] Mit der Schrägstrich-Regel «ignore» (Standard) wird ein abschliessender `/` ignoriert, mit «strict» muss er übereinstimmen; ein ungültiger oder leerer Wert gilt als «ignore»
- [x] Prozentkodierte Segmente werden vor dem Vergleich dekodiert; mehrfache Schrägstriche werden zu einem zusammengefasst
- [x] Die Gewichte für Pfadsegment, Query-Paar, Wildcard-Segment und exakten Treffer sind konfigurierbar
- [ ] Ohne Konfiguration gelten die Standardgewichte Pfadsegment 10, Query-Paar 5, Wildcard-Segment 1 und exakter Treffer 50
- [x] Alle Werte werden aus der Startkonfiguration gelesen; Änderungen erfordern einen Neustart

## Hinweise

- Der Wert für Wildcard-Segmente wird zum Score addiert, nicht abgezogen, obwohl er in der Konfiguration «Penalty» heisst.
- Belegende Tests: `RuleMatchingConfigFactoryTests`, `RuleMatchingServiceTests`, `RuleCacheServiceTests`.

## Offene Fragen

- [ ] **F1 · Laufzeit-Schalter «Case-sensitive Link-Erkennung» ohne Wirkung:** Die Laufzeit-Einstellung `CaseSensitiveLinkDetection` wird im Admin-Panel angeboten und gespeichert, laut Beschreibung soll sie die Startkonfiguration übersteuern. Das Matching liest aber ausschliesslich die Startkonfiguration.
  - Option A: Matching berücksichtigt den Laufzeit-Schalter (inklusive Neuaufbau des Index für «Wildcard») — ✅ Einstellung wirkt ohne Neustart / ❌ Cache-Index muss bei Änderung neu aufgebaut werden
  - Option B: Laufzeit-Schalter entfernen, nur die Startkonfiguration gilt — ✅ eine einzige Quelle / ❌ Umschalten erfordert weiterhin einen Neustart
  - **Empfehlung:** Option B, weil die Startkonfiguration bereits greift und ein zweiter Schalter mit Index-Neuaufbau mehr Risiko als Nutzen bringt.
