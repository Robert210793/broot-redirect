# US-04.002: Suchen und Ersetzen pro Regel

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** für eine Regel Textstellen in der erzeugten URL ersetzen
**damit** ich Abweichungen zwischen alter und neuer Struktur (z. B. umbenannte Ordner) korrigieren kann, ohne weitere Regeln anzulegen

## Akzeptanzkriterien

- [x] Die Ersetzungen einer Regel werden in Listenreihenfolge auf die URL aus dem Basisschritt angewendet
- [x] Der Suchbegriff wird literal behandelt, nicht als regulärer Ausdruck
- [x] Pro Eintrag ist wählbar, ob Gross-/Kleinschreibung beachtet wird
- [x] Ein leerer Suchbegriff lässt die URL unverändert; ein leerer Ersatz entfernt die gefundene Stelle
- [ ] Ein fehlerhafter Eintrag lässt die URL unverändert, statt die Weiterleitung abzubrechen

## Hinweise

- Die regelspezifischen Ersetzungen laufen vor den globalen Regeln (US-06.002).
- Belegende Tests: `UrlTransformServiceTests`.
