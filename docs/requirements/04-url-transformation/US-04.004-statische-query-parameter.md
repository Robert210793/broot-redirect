# US-04.004: Statische Query-Parameter anhängen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** pro Regel feste Query-Parameter an jede erzeugte URL anhängen
**damit** das Ziel zusätzliche Angaben erhält, etwa eine Ansicht oder eine Herkunftskennung

## Akzeptanzkriterien

- [x] Die statischen Parameter einer Regel werden als Key/Value-Paare an die URL angehängt
- [x] Pro Parameter lässt sich die Kodierung des Werts überspringen
- [x] Einträge ohne Key werden übersprungen
- [x] Die Parameter werden vor einem allfälligen Fragment eingefügt
- [ ] Statische Parameter werden immer zuletzt angehängt, nach allen anderen Transformationsschritten

## Hinweise

- Belegende Tests: `UrlTransformServiceTests`.
