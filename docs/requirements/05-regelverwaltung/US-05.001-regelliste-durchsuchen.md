# US-05.001: Regelliste anzeigen, durchsuchen und sortieren

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** alle Weiterleitungsregeln in einer durchsuchbaren und sortierbaren Liste sehen
**damit** ich auch bei Tausenden von Regeln eine bestimmte Regel schnell finde

## Akzeptanzkriterien

- [x] Die Liste ist seitenweise aufgeteilt; Standard sind 50 Regeln pro Seite, höchstens 500; ungültige Werte für Seite oder Anzahl fallen auf die Standardwerte zurück
- [x] Die Suche filtert nach Matcher, Ziel-URL und Info-Text
- [x] Die Liste lässt sich auf- und absteigend nach Matcher, Ziel-URL, Typ und Erstelldatum sortieren; ein unbekanntes Sortierfeld sortiert nach Erstelldatum
- [ ] Die Liste lässt sich nach Herkunft sortieren
- [ ] Jede Zeile zeigt Matcher, Ziel-URL, Typ, Herkunft (Manuell, Importiert, Unbekannt) sowie Kennzeichen für Auto-Weiterleitung und Info-Text
- [ ] Die Spaltenbreiten lassen sich verstellen und bleiben im Browser gespeichert
- [ ] Ohne Regeln zeigt die Seite «Keine Weiterleitungsregeln gefunden.» mit dem Hinweis, die erste Regel zu erstellen
- [ ] Die Liste bietet Schaltflächen zum Export als JSON, CSV und XLSX (siehe US-07.005)

## Hinweise

- Die Liste wird aus dem In-Memory-Cache bedient, nicht aus dem Storage.
- Belegende Tests: `RulesControllerTests`, `RuleImportExportServiceTests`.
