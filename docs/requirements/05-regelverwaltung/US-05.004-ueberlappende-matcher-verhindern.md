# US-05.004: Überlappende Matcher verhindern

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** gewarnt werden, wenn eine neue Regel eine bestehende verschluckt oder von ihr verschluckt wird
**damit** keine Regel unbemerkt wirkungslos wird

## Akzeptanzkriterien

- [x] Ein Matcher vom Typ «Teilweise», der hierarchisch unter oder über einer bestehenden Regel vom Typ «Teilweise» liegt (z. B. `/a/b` und `/a/b/c`), wird mit 409 und dem Code `MATCHER_CONFLICT` samt konfliktierender Regel abgewiesen
- [x] Eine Regel vom Typ «Wildcard» steht nie im Konflikt mit einer Regel vom Typ «Teilweise», weder darunter noch darüber; sie wird über den exakten Pfad vor jeder «Teilweise»-Regel gefunden und kann nicht verschluckt werden (geändert 2026-10-29, Korrektur K3 in [US-13.003](../13-qm-pro-integration/US-13.003-bereichsregeln-abgleichen.md); vorher war der Typ des kürzeren Matchers massgebend)
- [x] Regeln vom Typ «Wildcard» für einen Ordner und für Dateien darunter dürfen nebeneinander bestehen
- [x] Domain-Regeln, Regex-Regeln und gleich lange Matcher werden nicht geprüft
- [x] Für den Vergleich wird die Query ignoriert und jedes Segment dekodiert; kodierte und dekodierte Schreibweise desselben Pfads gelten als gleich, ein kodiertes `%2F` erzeugt kein zusätzliches Segment
- [x] Beim Bearbeiten wird die Regel selbst ausgenommen und ein mitgeänderter Typ berücksichtigt
- [ ] Das Admin-Panel zeigt den Konflikt mit der konfliktierenden Regel in einem Dialog

## Hinweise

- Belegende Tests: `RuleCacheServiceTests`, `RulesControllerTests`; Vorrang der «Wildcard»-Regel vor einem darüberliegenden Ordner: `RuleMatchingServiceTests`.
- Zwei «Teilweise»-Regeln konkurrieren über den Score (Segmente, Query-Paare, Platzhalter). Ein kürzerer Ordner mit Query-Bedingungen kann einen tieferen überbieten; deshalb bleibt die Prüfung zwischen ihnen bestehen.
