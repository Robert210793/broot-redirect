# US-05.005: Einzelne oder mehrere Regeln löschen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** einzelne oder ausgewählte Regeln löschen
**damit** veraltete oder fehlerhafte Regeln nicht mehr greifen

## Akzeptanzkriterien

- [x] Eine einzelne Regel lässt sich löschen; eine unbekannte Regel ergibt 404
- [x] Mehrere Regeln lassen sich in einem Schritt löschen; die Antwort nennt die Anzahl gelöschter und nicht gefundener Regeln
- [x] Ungültige oder unbekannte IDs sowie Fehler beim Löschen einzelner Regeln zählen als «nicht gefunden», ohne den Vorgang abzubrechen
- [x] Eine leere Auswahl wird mit 400 abgewiesen
- [ ] In der Liste lassen sich Regeln per Mehrfachauswahl markieren; vor dem Löschen erscheint eine Bestätigung
- [ ] Nach dem Löschen erscheint eine Erfolgs- oder Fehlermeldung und die Liste wird aktualisiert

## Hinweise

- Belegende Tests: `RulesControllerTests`, `RuleCacheServiceTests`.
