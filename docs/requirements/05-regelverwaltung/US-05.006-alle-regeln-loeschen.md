# US-05.006: Alle Regeln löschen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** sämtliche Regeln in einem Schritt löschen
**damit** ich ein Regelwerk vor einem vollständigen Neuimport zurücksetzen kann

## Akzeptanzkriterien

- [x] Das Löschen aller Regeln startet einen Hintergrundauftrag und liefert sofort dessen ID und die Gesamtzahl
- [x] Der Fortschritt eines Auftrags lässt sich abfragen; ein unbekannter Auftrag ergibt 404
- [ ] Vor dem Start erscheint eine Bestätigung; während des Laufs zeigt die Liste «Regeln werden gelöscht...» mit Fortschritt
- [ ] Abgeschlossene Aufträge verfallen 5 Minuten nach Abschluss

## Hinweise

- Der Auftragszustand liegt nur im Arbeitsspeicher und überlebt keinen Neustart.
- Belegende Tests: `RulesControllerTests`, `TableStorageRuleRepositoryTests`.
