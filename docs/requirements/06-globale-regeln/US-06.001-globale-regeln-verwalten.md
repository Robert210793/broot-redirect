# US-06.001: Globale Such-und-Ersetzen-Regeln verwalten

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** Such-und-Ersetzen-Regeln pflegen, die für alle Weiterleitungen gelten
**damit** ich flächendeckende Änderungen (z. B. ein umbenanntes Pfadsegment) einmal statt in Hunderten von Regeln erfasse

## Akzeptanzkriterien

- [x] Globale Regeln lassen sich auflisten, einzeln abrufen, anlegen, ändern und löschen; eine unbekannte Regel ergibt 404
- [ ] Eine globale Regel besteht aus Suchbegriff (Pflicht), Ersatztext, Schalter für Gross-/Kleinschreibung und Priorität
- [x] Die Liste ist nach Priorität aufsteigend sortiert, bei gleicher Priorität nach Erstelldatum
- [ ] Die Seite «Globale Regeln» zeigt die Regeln in einer Tabelle und erklärt, dass tiefere Prioritätszahlen zuerst ausgeführt werden und globale Regeln nach den regelspezifischen Ersetzungen laufen
- [ ] Ohne Regeln zeigt die Seite «Keine globalen Regeln definiert.»

## Hinweise

- Globale Regeln sind vollständig im Arbeitsspeicher gecacht.
- Belegende Tests: `GlobalRulesControllerTests`, `GlobalRuleCacheServiceTests`, `TableStorageGlobalRuleRepositoryTests`.
