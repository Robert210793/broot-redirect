# US-06.002: Globale Regeln auf jede Ziel-URL anwenden

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich**, dass globale Regeln auf jede erzeugte Ziel-URL wirken
**damit** flächendeckende Ersetzungen ohne Änderung einzelner Regeln greifen

## Akzeptanzkriterien

- [x] Alle globalen Regeln werden nach Priorität aufsteigend auf die Ziel-URL angewendet
- [x] Der Suchbegriff wird literal behandelt; der Schalter für Gross-/Kleinschreibung wird beachtet
- [x] Ein leerer Suchbegriff lässt die URL unverändert; ein leerer Ersatztext entfernt die gefundene Stelle
- [ ] Globale Regeln laufen nach den regelspezifischen Ersetzungen und vor der Query-Strategie

## Hinweise

- Belegende Tests: `UrlTransformServiceTests`.
