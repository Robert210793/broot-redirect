# US-07.001: Import-Vorschau anzeigen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** vor einem Import sehen, welche Regeln neu, geändert, unverändert oder ungültig sind
**damit** ich einen fehlerhaften Import erkenne, bevor er das Regelwerk verändert

## Akzeptanzkriterien

- [x] Eine Datei (CSV, XLSX, JSON) oder eingefügtes JSON wird eingelesen und mit den bestehenden Regeln verglichen, ohne etwas zu speichern
- [x] Jeder Eintrag wird als «Neu», «Aktualisierung», «Unverändert» oder «Ungültig» eingestuft; die Antwort enthält die Anzahl pro Kategorie
- [x] Ein Eintrag gilt als «Aktualisierung», wenn eine Regel mit derselben ID oder demselben Matcher existiert und sich der Inhalt unterscheidet
- [x] Ein Eintrag ohne Matcher, mit ungültigem Typ oder mit Validierungsfehler gilt als «Ungültig»
- [x] Matcher und Ziel-URL werden für den Vergleich prozentkodiert
- [x] Die Vorschau zeigt höchstens 1000 Einträge
- [x] Leere oder nicht lesbare Eingaben werden mit 400 abgewiesen; nicht unterstützte Dateiendungen ergeben einen Fehler
- [ ] Die Seite «Regeln importieren» bietet «Datei auswählen» und «JSON einfügen», zeigt während der Analyse «Datei wird analysiert...» und listet die Einträge mit Status, filterbar nach Kategorie

## Hinweise

- Belegende Tests: `RulesControllerTests`, `RuleImportExportServiceTests`.
