# US-07.002: Import mit Fortschrittsanzeige ausführen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** viele Regeln auf einmal aus einer Datei importieren und den Fortschritt verfolgen
**damit** ich ein Migrationsregelwerk mit Tausenden von Einträgen ohne Einzelerfassung einspielen kann

## Akzeptanzkriterien

- [x] Der Import startet einen Hintergrundauftrag und liefert sofort dessen ID und die Gesamtzahl
- [x] Leere oder nicht lesbare Eingaben werden mit 400 abgewiesen
- [ ] Neu angelegte Regeln erhalten die Herkunft «Import»
- [ ] Jeder Eintrag wird einzeln validiert; ungültige Einträge landen in der Fehlerliste des Auftrags, die übrigen werden trotzdem importiert
- [ ] Die Seite zeigt während des Imports «Regeln werden importiert...» mit Fortschrittsbalken und danach «Import abgeschlossen» mit den Schaltflächen «Regeln anzeigen» und «Weiterer Import»
- [ ] Importierte Regeln wirken sofort, ohne Neustart

## Hinweise

- Abgleich mit bestehenden Regeln und Idempotenz sind in US-07.003 beschrieben.
- Der Auftragszustand liegt nur im Arbeitsspeicher und überlebt keinen Neustart.
- Belegende Tests: `RulesControllerTests`, `TableStorageRuleRepositoryTests`.
