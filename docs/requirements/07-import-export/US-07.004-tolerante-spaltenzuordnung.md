# US-07.004: Tolerante Spaltenzuordnung beim Import

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** Dateien mit unterschiedlichen, auch deutschen Spaltenüberschriften importieren
**damit** Exporte aus anderen Werkzeugen ohne Nachbearbeitung übernommen werden können

## Akzeptanzkriterien

- [x] CSV- und XLSX-Dateien mit englischen oder deutschen Spaltenüberschriften werden korrekt zugeordnet (z. B. «Matcher»/«Quelle», «Target URL»/«Ziel», «Type»/«Typ», «Info»/«Beschreibung», «Auto Redirect»/«Automatisch»)
- [x] Leere Zeilen in XLSX werden übersprungen
- [x] Die Listenfelder (beibehaltene und statische Query-Parameter, Suchen/Ersetzen) werden als JSON in einer einzelnen Zelle gelesen; ungültiges oder leeres JSON ergibt ein leeres Feld
- [x] Ein leeres Ja/Nein-Feld gilt als nicht gesetzt
- [x] Ein fehlender Typ gilt als «Teilweise»
- [x] Die Endung `.xls` wird als XLSX gelesen; JSON-Dateien werden unterstützt

## Hinweise

- Die vollständige Liste der akzeptierten Überschriften steht im Code bei der Spaltenzuordnung des Import/Export-Dienstes.
- Belegende Tests: `RuleImportExportServiceTests`.
