# US-07.005: Regeln als JSON, CSV oder XLSX exportieren

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** das gesamte Regelwerk als Datei herunterladen
**damit** ich es sichern, extern bearbeiten oder in eine andere Umgebung übertragen kann

## Akzeptanzkriterien

- [x] Der Export liefert alle Regeln als JSON, CSV oder XLSX; ein unbekanntes Format ergibt JSON; auch ohne Regeln entsteht eine Datei
- [x] Die CSV-Datei ist UTF-8 mit BOM und enthält die erwarteten Spaltenüberschriften
- [x] Werte mit Kommas und Anführungszeichen überstehen einen Export und Re-Import unverändert; ein vollständiger Durchlauf erhält alle Felder
- [x] Werte, die als Formel interpretiert werden könnten (z. B. beginnend mit `=` oder `+`), werden beim Export mit einem führenden Hochkomma entschärft und beim Import wieder zurückgewandelt
- [ ] Nach dem Herunterladen erscheint die Meldung «Export heruntergeladen.», bei einem Fehler «Export fehlgeschlagen.»

## Hinweise

- Belegende Tests: `RulesControllerTests`, `RuleImportExportServiceTests`.
