# US-08.001: URL-Liste gegen das Regelwerk prüfen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** eine Liste alter URLs eingeben und für jede sehen, welche Regel greift und wohin sie führt
**damit** ich das Regelwerk vor dem Go-live oder nach einer Änderung prüfen kann, ohne echte Aufrufe auszulösen

## Akzeptanzkriterien

- [x] Bis zu 500 URLs werden pro Prüfung angenommen; keine oder mehr als 500 URLs werden mit 400 abgewiesen
- [x] Leere Zeilen werden übersprungen
- [x] Pro URL meldet die Prüfung, ob eine Regel greift, und zählt die Treffer
- [ ] Zu jedem Treffer liefert die Prüfung Regel-ID, Matcher, Typ, Score, Qualität, Ampelstufe und aufgelöste Ziel-URL
- [x] URLs ohne Treffer werden als «Kein Treffer» mit Stufe Rot gemeldet
- [x] Ein Fehler bei einer einzelnen URL wird als Fehler dieser URL gemeldet, ohne die übrigen abzubrechen
- [ ] Die Seite «URL Validierung» nimmt die URLs zeilenweise entgegen (relative Pfade oder vollständige URLs) und zeigt die Ergebnisse in einer nach «Treffer» und «Kein Treffer» filterbaren Tabelle
- [ ] Die Prüfung schreibt keine Tracking-Einträge

## Hinweise

- Die Prüfung verwendet das Smart-Search-Verhalten nicht: URLs ohne Regel erscheinen als «Kein Treffer», auch wenn im Live-Betrieb eine Smart Search greifen würde.
- Belegende Tests: `RulesControllerTests`.
