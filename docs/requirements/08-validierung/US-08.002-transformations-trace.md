# US-08.002: Transformation Schritt für Schritt nachvollziehen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** für eine geprüfte URL sehen, welcher Schritt die Ziel-URL wie verändert hat
**damit** ich nachvollziehen kann, warum eine Regel eine unerwartete URL erzeugt

## Akzeptanzkriterien

- [x] Der Trace beginnt mit der eingegebenen URL und endet mit der finalen Ziel-URL, die dem gelieferten Ergebnis entspricht
- [ ] Nach dem Eingabeschritt folgt ein Schritt mit der getroffenen Regel, ihrem Typ, Score und ihrer Qualität
- [x] Der Basisschritt nach Regeltyp erscheint im Trace
- [x] Suchen/Ersetzen der Regel, globale Regeln, Query-Strategie (weitergeben, filtern, verwerfen) und statische Parameter erscheinen nur, wenn sie die URL tatsächlich verändert haben; mehrere Ersetzungen erscheinen einzeln
- [ ] In der Ergebnistabelle lässt sich eine Zeile aufklappen, um den «Transformation Trace» zu sehen

## Hinweise

- Belegende Tests: `UrlTransformServiceTests`, `RulesControllerTests`.
