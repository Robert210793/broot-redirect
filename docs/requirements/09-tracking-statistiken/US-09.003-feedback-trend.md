# US-09.003: Feedback-Trend über die Zeit anzeigen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** die Entwicklung des Feedbacks über die Zeit sehen
**damit** ich erkenne, ob Korrekturen am Regelwerk die Zufriedenheit verbessern

## Akzeptanzkriterien

- [x] Der Trend liefert die Feedback-Zahlen pro Tag, Woche oder Monat über eine wählbare Anzahl Tage
- [x] Ohne gültige Angaben gelten 30 Tage und die Aggregation pro Tag
- [ ] Die Seite zeigt den «Feedback-Trend» als Diagramm mit Umschaltung «Tag», «Woche», «Monat»; ohne Daten erscheint «Keine Trend-Daten vorhanden.»

## Hinweise

- Belegende Tests: `TrackingControllerTests`, `TableStorageTrackingRepositoryTests`.
