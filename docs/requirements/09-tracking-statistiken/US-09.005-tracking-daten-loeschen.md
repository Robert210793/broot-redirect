# US-09.005: Tracking-Daten löschen und automatisch aufräumen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Betreiber
**möchte ich**, dass Tracking-Daten nach einer festen Frist gelöscht werden und sich bei Bedarf vollständig entfernen lassen
**damit** keine Nutzungsdaten länger als nötig gespeichert bleiben

## Akzeptanzkriterien

- [x] Ein Hintergrunddienst löscht Einträge, die älter als die konfigurierte Aufbewahrungsdauer sind
- [x] Ein Fehler beim Löschen beendet den Dienst nicht; er läuft beim nächsten Durchgang weiter und stoppt sauber beim Herunterfahren
- [ ] Der Dienst läuft alle 24 Stunden; die Aufbewahrungsdauer beträgt standardmässig 30 Tage
- [x] Administratoren können sämtliche Tracking-Daten löschen; die Antwort nennt die Anzahl gelöschter Einträge
- [ ] Vor dem Löschen aller Daten erscheint die Bestätigung «Alle Tracking-Daten löschen?» mit dem Hinweis, dass dies nicht rückgängig gemacht werden kann

## Hinweise

- Die Aufbewahrungsdauer ist Startkonfiguration und erfordert einen Neustart.
- Belegende Tests: `TrackingCleanupServiceTests`, `TrackingControllerTests`, `TableStorageTrackingRepositoryTests`.
