# US-10.003: Smart Search konfigurieren

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** festlegen, wie aus einer alten URL ohne Regel eine Suchanfrage entsteht
**damit** die Smart Search zur Suchfunktion der neuen Ablage passt

## Akzeptanzkriterien

- [ ] Die Einstellungen erfassen «Such-URL-Vorlage», «Suchbegriff-Regex» und «URL-Kodierung überspringen»
- [x] Eine leere Such-URL-Vorlage deaktiviert die Smart Search
- [x] Ein leerer Regex verwendet das letzte Pfadsegment als Suchbegriff
- [x] Ein Wechsel des Regex wird ohne Neustart wirksam

## Hinweise

- Der Regex wird beim Speichern nicht geprüft; ein ungültiger Regex fällt beim Suchen still auf das letzte Pfadsegment zurück.
- Die Smart Search greift nur, wenn «Verhalten bei keinem Treffer» auf «Intelligente Suche (Fallback)» steht (siehe US-01.004).
- Belegende Tests: `SmartSearchServiceTests`.
