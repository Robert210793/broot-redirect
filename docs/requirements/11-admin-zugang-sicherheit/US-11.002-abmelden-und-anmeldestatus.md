# US-11.002: Abmelden und Anmeldestatus prüfen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** meinen Anmeldestatus sehen und mich abmelden können
**damit** ich das Admin-Panel an einem geteilten Gerät sicher verlassen kann

## Akzeptanzkriterien

- [x] Der Anmeldestatus meldet, ob eine Admin-Session besteht, und den Zeitpunkt der Anmeldung; fehlt der Zeitpunkt oder ist er ungültig, wird keiner gemeldet
- [x] Das Abmelden beendet die Session
- [x] Anmeldestatus und Abmelden erfordern eine bestehende Session
- [ ] Die Navigation des Admin-Panels bietet «Abmelden»
- [ ] Antwortet die API mit 403, wechselt das Admin-Panel zur Anmeldeseite (ausgenommen Anmeldung und Statusabfrage selbst)

## Hinweise

- Der Routen-Guard im Frontend lässt alle Admin-Seiten zu; geschützt wird ausschliesslich serverseitig. Eine Admin-Seite wird daher kurz angezeigt, bevor die 403-Antwort zur Anmeldeseite führt.
- Belegende Tests: `AuthControllerTests`, `AdminSessionMiddlewareTests`.
