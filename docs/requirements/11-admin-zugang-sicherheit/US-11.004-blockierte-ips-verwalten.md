# US-11.004: Blockierte IPs verwalten

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** gesperrte IPs einsehen, manuell sperren und wieder freigeben
**damit** ich auf Angriffe reagieren und versehentlich gesperrte Kollegen freischalten kann

## Akzeptanzkriterien

- [x] Die Liste zeigt alle gesperrten IPs mit Anzahl Fehlversuche und Ende der Sperre
- [x] Eine IP lässt sich manuell sperren; eine bereits gesperrte IP ergibt 409 und eine leere Angabe 400
- [x] Eine IP lässt sich freigeben (auch URL-kodiert übermittelt); eine leere Angabe ergibt 400
- [x] Alle Sperren und Fehlversuche lassen sich in einem Schritt aufheben
- [ ] Die Seite «Blockierte IPs» zeigt IP-Adresse, Fehlversuche, «Blockiert bis» und verbleibende Zeit, bietet «IP-Adresse manuell blockieren» und fragt vor «Alle Blockierungen aufheben?» nach einer Bestätigung
- [ ] Ohne Sperren zeigt die Seite «Keine IPs sind derzeit blockiert.»

## Hinweise

- Belegende Tests: `AuthControllerTests`, `BruteForceProtectionServiceTests`.
