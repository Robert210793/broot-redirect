# US-12.001: Betriebszustand über einen Health-Endpunkt melden

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Betreiber
**möchte ich** den Zustand der Anwendung über einen Endpunkt abfragen
**damit** die Plattform eine nicht bereite oder gestörte Instanz erkennt und keine Anfragen dorthin leitet

## Akzeptanzkriterien

- [x] Der Endpunkt meldet «healthy» mit 200, wenn Table Storage erreichbar und der Cache aufgewärmt ist
- [x] Ist der Cache noch nicht aufgewärmt oder tritt dabei ein Fehler auf, meldet er «unhealthy» mit 503 und dem Status «warming up» bzw. «error» für den Cache
- [ ] Ist Table Storage nicht erreichbar, meldet er «unhealthy» mit 503 und der Fehlermeldung
- [ ] Die Antwort enthält Version, Zeitstempel, Laufzeit seit dem Start, Anzahl Regeln und die Antwortzeiten der Prüfungen
- [ ] Der Endpunkt ist ohne Anmeldung erreichbar

## Hinweise

- Der Health-Probe der Plattform sollte auf diesen Endpunkt zeigen.
- Belegende Tests: `HealthControllerTests`.
