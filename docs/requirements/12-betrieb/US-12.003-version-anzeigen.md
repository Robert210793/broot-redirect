# US-12.003: Installierte Version anzeigen

> **Bestandsaufnahme:** Nachträglich aus dem Code abgeleitet (Stand 2026-10-24). Dokumentiert das Ist-Verhalten. `[x]` = durch automatisierte Tests belegt, `[ ]` = umgesetzt, aber ohne automatisierten Test. Keine fachliche Freigabe, keine Abnahme.

**Als** Administrator
**möchte ich** sehen, welche Version der Anwendung läuft
**damit** ich Fehlermeldungen einer Version zuordnen und Deployments überprüfen kann

## Akzeptanzkriterien

- [ ] Die Fusszeile der Info-Seite zeigt die Version im Format «v1.2.3»
- [ ] Die Version wird beim Docker-Build in die Seite eingesetzt; fehlt sie (z. B. in der Entwicklung), wird sie über den Health-Endpunkt nachgeladen, auch wenn dieser 503 meldet
- [ ] Ohne bekannte Version wird keine Version angezeigt

## Hinweise

- Die Version stammt aus dem Git-Tag, den die CI-Pipeline bei `feat`-, `fix`- und `perf`-Commits erzeugt.
