# Epic 13: QM-Pro-Integration

## Übersicht

Schnittstelle für QM Pro 365: Beim Publizieren eines Dokuments schreibt QM Pro die Weiterleitungsregel von der alten On-Premises-URL auf die Publikations-URL, beim Zurückziehen deaktiviert QM Pro die Regel.
